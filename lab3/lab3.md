## Цілі

- Написати запити `SELECT` для отримання даних (включаючи фільтрацію за допомогою `WHERE` та вибір певних стовпців).
- Практикувати використання операторів `INSERT` для додавання нових рядків до таблиць.
- Практикувати використання оператора `UPDATE` для зміни існуючих рядків (використовуючи `SET` та `WHERE`).
- Практикувати використання операторів `DELETE` для безпечного видалення рядків (за допомогою `WHERE`).
- Вивчити основні операції маніпулювання даними (DML) у PostgreSQL та спостерігати за їхнім впливом.

## Опис виконання роботи: 
У ході виконання лабораторної роботи було здійснено роботу з базою даних інтернет-магазину в середовищі PostgreSQL. На основі раніше створеної 
структури таблиць було виконано операції маніпулювання даними (DML).Було реалізовано запити типу SELECT для отримання інформації з таблиць, зокрема 
з використанням умов WHERE для фільтрації даних та вибору необхідних стовпців. Також були використані запити з об'єднанням таблиць (JOIN) для 
отримання пов'язаної інформації.За допомогою оператора INSERT було додано нові записи до таблиць, зокрема клієнтів, брендів, категорій та товарів. 
Після кожної операції перевірявся результат за допомогою SELECT-запитів. Операції UPDATE використовувалися для зміни існуючих даних, таких як 
електронна пошта клієнтів, кількість товарів на складі та статуси замовлень і оплат. Перед оновленням виконувалась перевірка відповідних записів.
За допомогою оператора DELETE було виконано видалення окремих записів з таблиць із дотриманням умов цілісності даних. Перед видаленням здійснювалась 
перевірка залежних записів у пов’язаних таблицях.

## Висновок:
У ході виконання лабораторної роботи було освоєно основні операції маніпулювання даними (DML) у PostgreSQL. Було реалізовано запити типів SELECT, 
INSERT, UPDATE та DELETE, що дозволило отримувати, додавати, змінювати та видаляти дані в таблицях бази даних. Під час роботи було закріплено 
навички використання умов WHERE для фільтрації записів, а також розуміння важливості дотримання цілісності даних при роботі із зовнішніми ключами. 
У результаті виконання лабораторної роботи було перевірено коректність функціонування бази даних у режимі OLTP та сформовано практичні навички роботи 
з SQL-запитами для обробки транзакцій.
